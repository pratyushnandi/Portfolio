04 ai_pipeline

How an intelligent system sees

Scroll to bring a vision pipeline online, one stage at a time: from a raw camera frame to an action in the real world.

  1. A frame arrives from a live camera feed, streamed over RTSP.

  2. The frame is decoded and split into the grid of values a model can read.

  3. OpenCV cleans the signal and brings out shapes and edges.

  4. A detection model, such as YOLO, reads the whole frame in a single pass.

  5. It returns every object it finds, each with a box and a confidence score.

  6. Rules turn detections into meaning: this car crossed the stop line on red.

  7. An alert goes to a person to review. The same loop drives Detectify.

06 how_i_build

Not just interfaces. Systems.

The loop every project goes through, from idea to optimisation, shown on the one system you can inspect right now: this portfolio.

01/ 08Idea

  1. 01

    Idea

    Start from the problem and the people who have it, then decide what the system must do.

    here A portfolio that reads like an engineering product and is honest about every claim it makes.

  2. 02

    Architecture

    Choose the simplest structure that holds, and draw the system before writing it.

    here Plain HTML, CSS and JavaScript: no framework, no build step, one design system.

  3. 03

    Development

    Small, reviewable changes, with one source of truth for anything shared.

    here One knowledge model drives the system map, the command palette and the assistant.

  4. 04

    Integration

    Connect external services behind clear contracts, and plan for them failing.

    here The contact form posts to Web3Forms; if that fails, a prefilled email link takes over.

  5. 05

    Testing

    Automate whatever a person would otherwise have to check by hand.

    here Playwright end-to-end tests on desktop and mobile, plus HTML, CSS and JavaScript linting.

  6. 06

    Deployment

    Every change passes review and an automated gate before it ships.

    here Pull requests run CI; Vercel deploys previews and production, and GitHub Pages mirrors it.

  7. 07

    Monitoring

    Check what people actually receive, after it ships, not only before.

    here Every deployment triggers a smoke test against the live URL.

  8. 08

    Optimisation

    Measure first, then improve what the numbers point at.

    here Lighthouse budgets in CI, with accessibility at 100 and zero main-thread blocking.

Think → Build → Test → Deploy → Improve ↺The loop: think, build, test, deploy, improve, then repeat.
