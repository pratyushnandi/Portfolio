# Personal Portfolio Website

A modern and responsive personal portfolio website showcasing my skills, projects, and experience in web development. Built using HTML, CSS, and JavaScript with smooth animations, interactive UI elements, and a fully functional contact form powered by EmailJS.

* Responsive Design
* Animated Background Effects
* Interactive Project Modals
* Tech Stack Categories
* Smooth Scrolling
* AOS Scroll Animations
* EmailJS Contact Form Integration
* Modern Dark UI
